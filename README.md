# KEYSPACE

직접 타이핑하며 가지고 노는 75% 기계식 키보드. React + TypeScript + Three.js + Vite로 만든, 백엔드 없는 한 화면의 인터랙티브 작품입니다.

## 실행

Node.js 22.12 이상 또는 24 LTS 환경을 권장합니다. 검증 환경은 Node.js 24.7입니다.

```sh
git clone https://github.com/qkrwoghd04/keyspace.git
cd keyspace
npm ci
npm run dev
```

브라우저에서 **http://127.0.0.1:5180**을 여세요. 다른 프로젝트의 개발 서버와 충돌하지 않도록 포트를 지정했습니다. 이미 사용 중이면 `npm run dev -- --port 5181`처럼 변경할 수 있습니다.

```sh
npm run check    # TypeScript 검사
npm run build    # dist/에 배포용 정적 파일 생성
npm run preview  # http://127.0.0.1:4180 에서 배포 빌드 확인
```

다른 컴퓨터에서는 프로젝트 폴더로 이동한 뒤 같은 명령을 실행하세요. `dist/`의 파일을 정적 호스팅에 올릴 수 있습니다. 상대 경로를 사용하므로 개인 사이트의 하위 경로에도 배포할 수 있습니다.

## 사용

- 데스크톱은 처음 열면 바로 타이핑할 수 있습니다. 입력창을 클릭해 다시 포커스할 수 있습니다.
- 물리 키와 화면의 키가 함께 움직입니다. 여러 키를 누르거나 길게 눌러도 독립적으로 유지됩니다.
- 화면의 키를 클릭하거나 탭해도 누를 수 있습니다. 문자 키는 입력창의 현재 선택 영역에 입력됩니다.
- **Reset**은 입력한 문장과 눌림 상태를 비웁니다. **Sound**는 선택 기능이며 처음에는 꺼져 있습니다.
- 모바일에서는 입력창을 탭하면 소프트웨어 키보드를 사용할 수 있습니다.

## 구현 구조

| 파일 | 책임 |
| --- | --- |
| `src/App.tsx` | 실제 textarea, IME 이벤트, 포커스 표시, 최소한의 컨트롤 |
| `src/components/KeyboardScene.tsx` | React와 3D 씬의 연결, WebGL 대체 안내 |
| `src/keyboard/layout.ts` | 82개 키의 위치·너비·각인·물리 code |
| `src/keyboard/geometry.ts` | 둥근 모서리, 테이퍼와 얕은 곡면을 가진 키캡 생성 |
| `src/keyboard/legends.ts` | 로컬 Canvas 각인 아틀라스 및 표면 지오메트리 |
| `src/keyboard/Keycap.ts` | 개별 키의 빠른 하강, 절제된 스프링 복귀와 잔광 |
| `src/keyboard/KeyboardModel.ts` | 하우징, 플레이트, 베젤, 키캡, 소재와 GPU 자원 정리 |
| `src/keyboard/Studio.ts` | 카메라·조명·그림자·Raycaster·포인터·필요할 때만 렌더링 |
| `src/input/KeyboardInput.ts` | `KeyboardEvent.code` 기반 물리 상태와 입력 소스별 눌림 추적 |
| `src/input/SwitchSound.ts` | 외부 음원 없는 짧은 Web Audio 스위치 사운드 |

물리 키 판별과 문자열 편집은 독립적입니다. `event.key`를 이어 붙이지 않고 textarea의 정상적인 입력·조합·삭제·붙여넣기 흐름을 그대로 사용합니다. 애니메이션은 Three.js 객체를 직접 갱신하며 프레임마다 React 상태를 갱신하지 않습니다. 지오메트리·재질·각인 아틀라스를 공유하고, 최대 픽셀 비율은 2로 제한합니다. 정지 상태에서는 연속 렌더링을 중단합니다.

입력한 문장은 전송하거나 저장하지 않습니다. 앱에는 분석 도구, API 요청, 쿠키, localStorage, 백엔드가 없습니다. 모델·각인·그림자·음원은 코드로 생성되며 외부 모델이나 런타임 폰트 다운로드가 필요 없습니다.

## 검증한 범위

- TypeScript 검사 및 Vite 배포 빌드 통과. 배포용 preview에서도 3D 렌더링과 타이핑을 확인했고 콘솔 오류가 없었습니다.
- 배열과 입력 컨트롤러의 이벤트 검증 7,207개 assertion 통과: 82개 고유 code, 키 겹침·크기, 반복 입력, 동시 입력, 좌우 Shift, 물리/포인터 혼합, Meta 해제, blur·hidden, 연결·해제·재연결.
- 실제 브라우저 WebGL 씬에서 합성 키 이벤트로 12개 검사 통과: A의 하강, S의 독립 유지, 반복 입력 시 고정, 네 키 동시 입력, 개별 복귀, blur·hidden 초기화, 감소된 모션, 정지 시 렌더 중단, 82개 키/각인, 렌더링 및 자원 정리.
- 브라우저 키 입력으로 영문 타이핑·Enter·Backspace 검증. 한글 및 여러 줄 붙여넣기, Tab 이동, Reset, Sound 토글과 버튼 포커스 유지 확인. 화면의 A·S 키 직접 클릭으로 `as` 입력 확인.
- 1144 × 964, 1366 × 720 데스크톱 및 390 × 844, 320 × 568 모바일 뷰포트에서 키보드 전체 표시와 가로 넘침 없음 확인.
- WebGL 컨텍스트를 사용할 수 없도록 한 브라우저에서 대체 안내와 textarea 유지 확인.

자동 검증은 실제 운영체제의 한글 IME 조합이나 모바일 소프트웨어 키보드의 모든 동작을 재현하지 않습니다. 배포 전 사용하는 macOS/Windows 한글 입력기와 iOS/Android에서 조합·확정·삭제를 직접 확인하세요. 브라우저·운영체제가 전달하지 않는 단축키와 Fn 입력은 추적할 수 없습니다. Fn은 화면 탭으로만 반응하며, 75% 배열에 없는 키는 모델에 표시되지 않습니다. 기본 Tab 이동과 브라우저 단축키는 차단하지 않습니다.

## 아트 디렉션 조정

전체 여백·타이포그래피·색상은 `src/styles.css`, 키캡/하우징 색은 `KeyboardModel.ts`, 스튜디오 조명과 카메라는 `Studio.ts`에서 조정할 수 있습니다. 운영체제의 모션 감소 설정이 켜져 있으면 패럴랙스·탄성을 없애고 짧은 눌림 상태만 표시합니다.
