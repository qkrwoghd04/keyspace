# KEYSPACE

소재와 움직임이 서로 다른 14개 75% 키보드 컬렉션. 자유 입력 Playground와 나의 기록에 도전하는 Challenge. React + TypeScript + Three.js + Vite 기반의 백엔드 없는 인터랙티브 작품.

## 실행

검증 환경: Node.js 24.14.1, npm 11.11.0.

```sh
npm ci
npm run dev       # http://127.0.0.1:5180
npm run check     # TypeScript
npm test          # Vitest
npm run test:e2e   # 설치된 Google Chrome 사용, 기존 회귀와 Challenge 및 부하 검사
npm run build     # dist/ 정적 빌드
npm run preview   # http://127.0.0.1:4180
```

운영 주소: [keyspace.todah.dev](https://keyspace.todah.dev). 기존 Coolify 앱에서 GitHub `main`을 Railpack으로 빌드하고 `/dist`를 nginx로 제공하는 구성. `dist/` 정적 호스팅 및 하위 경로 배치 지원.

## 사용

- 1024px 이상: 240px 컬렉션 LNB, 내부 스크롤, 접기와 다시 열기 지원.
- CLASSIC 4개, EXPERIMENTAL 5개, ANIMATION 5개. 그룹별 접기와 펼치기, 현재 그룹 표시, NOW VIEWING으로 선택 테마 찾기 지원.
- 1024px 미만: 현재 테마 버튼으로 모달 시트 열기, 선택 후 닫기, Escape와 포커스 복귀 지원.
- Playground의 실제 textarea에서 일반 입력, 선택, 조합, 삭제, 줄바꿈과 붙여넣기 처리. 화면 키를 누르면 현재 선택 영역에 입력.
- 여러 물리 키와 포인터 입력의 독립적인 hold, 짧은 탭, 브라우저 자동 반복 입력 지원.
- 테마 변경 시 문장, 선택 영역, 음소거와 음량 유지. 기본 음소거, 기본 음량 50%.
- Reset은 문장과 눌림 및 이펙트 초기화. 테마와 사운드 설정 유지.
- 모바일 소프트웨어 키보드는 입력창을 직접 탭할 때만 사용. 3D 키 탭으로 입력창 강제 포커스 제외.

## Challenge

상단 모드 선택으로 진입. 기존 LNB는 테마 선택 전용이며 결과도 같은 화면의 입력 영역에 표시. 별도 대시보드, 계정, 실시간 멀티플레이, 글로벌 랭킹, 재화와 상점 없음.

- 한국어, 영어, 짧은 TypeScript 예제와 30초 / 60초 선택. 직접 작성한 지문을 버전별로 고정하고 14,000자 이상 준비. 코드 실행과 자동완성 없음.
- 시작과 재도전 버튼에서 native 입력창 포커스, 3초 카운트다운, 실제 경과 시간 기준 종료. 경기 중 테마, 언어, 시간, Ghost와 모드 변경 잠금. 취소 후 해제. 사운드와 효과 강도는 경기 중에도 조절 가능.
- 오타 뒤 진행 차단. 삭제로 되돌아간 위치는 현재 속도에서 제외되며 같은 위치 재입력으로 정확도 분모, 콤보와 연출 보상 중복 획득 불가.
- 영어와 코드 `WPM = 현재 정확한 문자 수 ÷ 5 ÷ 경과 분`. 한국어 `CPM = 현재 정확한 완성 문자 수 ÷ 경과 분`. NFC 정규화 grapheme 기준, 공백과 줄바꿈 포함.
- `정확도 = 정답으로 통과한 고유 위치 수 ÷ (고유 위치 수 + 누적 오타 수) × 100`. 오타 삭제 후에도 이력 유지. Backspace 자체는 오타 제외. 입력 전 정확도는 대시 표시.
- IME 조합 중 판정 없음. 확정 변경만 한 번 반영. 종료 시점에 확정되지 않은 조합과 마감 시각 이후 입력은 결과 제외.
- 경쟁 모드의 붙여넣기, 드롭과 실행 취소 차단. Playground의 정상 붙여넣기는 유지. 숨겨진 탭과 페이지 이탈은 경기 중단 및 저장 제외.
- 종료 시 최종 속도, 정확도, 최대 콤보, 직전 동일 조건 최고 기록과의 차이, 재도전과 해당 기록 Ghost 버튼 제공.

### Ghost와 이 브라우저의 기록

지문 ID, 버전, 언어, 종류, 제한 시간과 판정 규칙의 정확한 일치 필요. 저장된 실제 진행 위치를 시간별로 재생하며 멈춤과 삭제 후 후퇴도 유지. 평균 속도 기반 가상 상대 생성 없음. 진행 바 두 개와 같은 시점의 글자 차이만 표시하며 두 번째 3D 키보드 렌더링 없음.

`keyspace:challenge:v1` 저장소에 조건, 결과와 `[경과 ms, 정확한 위치]` 이력만 보관. 최근 20회와 조건별 최고 기록 보관. 10ms 안의 과밀 표본은 마지막 실제 관찰 지점으로 합치며 60초당 최대 6,002개 표본으로 제한. 저장 자료의 스키마, 지문 조건, 수치와 이력 검증 후 사용.

저장 실패 시 화면 결과 유지, Ghost 생성 비활성화, 저장 재시도 제공. 손상되거나 읽지 못한 기존 자료의 묵시적 덮어쓰기 없음. 삭제는 확인 후 Challenge 키만 제거하며 다른 브라우저 데이터는 유지. 삭제 실패 시 기존 기록 유지. 브라우저 저장소 직접 수정이나 개발 도구 조작까지 막는 서버 검증형 안티치트는 범위 밖.

### 콤보와 종료 연출

10 / 25 / 50개의 새로운 정확한 위치에서 3단계 강화. 콤보 배수와 추가 경쟁 점수 없음. 물리 키 눌림과 실제 소리는 기존 입력 경로, 보상은 게임 판정 이벤트 경로 사용. 효과 기본값은 약하게이며 기본 / 약하게 / 끄기 제공. 모션 감소에서는 콤보와 종료 모션 억제, 점수 계산 유지.

| 테마 | 정답과 콤보 보상 |
| --- | --- |
| Studio / Dark / Glass / Neon | 소재색 모서리 반응, 유리 파동, 인쇄색 연결 궤적 |
| Inferno | 불씨, 주변 균열 강화, 키 사이 불꽃 연결 |
| Glacier | 서리 결정, 내부 발광, 낮은 결정 연결 |
| Jelly | 작은 파동, 넓어지는 주변 키 탄성 |
| Grove | 잎과 꽃가루 반응, 다섯 잎 모양의 작은 개화 |
| Orbit | 별빛, 연결 궤적, 3단계에서 안정된 고리 |
| ANIMATION 5개 | 기존 물결, 동료, 만화 잔상, 성의 기구와 격납고의 정답 반응 및 테마색 연결 |

경기 중 Enter와 Space도 큰 대표 연출을 시작하지 않는 구조. 종료에서만 단일 피날레, 최고 기록에서 보조 궤적 추가. 모든 연출은 키보드의 3D 좌표에 제한된 풀로 표시하며 지문 위의 화면 오버레이 없음. 짧은 피날레 종료 후 동작 안정, 모드 전환 시 연출 리소스 정리.

판정, 저장, Ghost와 입력 검증의 상세 경계는 [Challenge 검증과 규칙](docs/challenge.md) 참고.

### ANIMATION

기존 키 배열을 유지하면서 하우징, 부속 장치와 렌더링을 작품의 요소로 재해석한 5개 장면.

| 테마 | 실루엣과 대기 상태 | 일반 타건 | Enter / Space | 별도 합성 사운드 |
| --- | --- | --- | --- | --- |
| 귀멸의 칼날 | 체크 래커 하우징, 도검 형태의 후면 레일, 낮게 흐르는 수면 부조 | 최근 입력 순서대로 연결되는 입체 물결과 가는 검격, 짧은 물방울 | 대각선 베기 / 키보드를 감싸는 물결 | 물의 마찰, 금속성 베기와 짧은 바람 |
| 포켓몬 | 옆으로 연결된 도감, 스캔 화면, 몬스터볼 장치, 귀와 꼬리를 가진 작은 동료의 호흡과 눈 깜빡임 | 동료가 입력 키 쪽을 바라보고 귀, 꼬리와 몸을 움직이며 화면 반응 | 몬스터볼 개방과 동료 점프 / 국소 충전 궤적과 스파크 | 플라스틱 장치 클릭, 짧은 전자성 팝 |
| 스파이더버스 | 어긋난 인쇄 판형 하우징, 셀 명암, 역방향 외피 외곽선과 절차적 망점 | CMY 잔상과 검은 동작선, 장식 잔상만 12fps 단계 표현 | 만화 충격 도형 / 두 겹의 패널 분할선 | 건조한 충격, 짧은 이중 잉크성 클릭 |
| 하울의 움직이는 성 | 보일러 하우징, 서로 다른 집과 굴뚝, 외부 톱니와 관절 다리, 천천히 도는 기어와 소량의 연기 | 해당 영역의 톱니, 창문 셔터, 굴뚝과 다리 반응 | 걸음 동작과 기계 전반의 반응 / 보일러 호흡과 창문 반응 | 목재성 몸통, 톱니 마찰과 짧은 공기음 |
| 에반게리온 | 장갑형 격납고, 후면 게이트, 전면 잠금 장치와 노출된 피스톤, 낮은 속도의 상태등 | 입력 영역의 잠금 해제 → 피스톤 상승 → 장갑판 전개 후 역순 복귀 | 영역별 순차 기동과 게이트 개방 / 압력 점검과 동시 인터록 | 유압성 저음과 시간차 잠금 클릭 |

대표 연출은 테마당 하나의 1.15초 실행과 0.2초 재시작 제한 사용. 실행 중 요청의 중첩, 연장과 대기열 생성 없음. 일반 타건 이펙트는 별도 풀에서 짧게 갱신. 이 제한은 연출에만 적용하며 native 글자 입력, 자동 반복, 줄바꿈과 물리 키 눌림은 그대로 처리.

### 외부 에셋 확보 상태

외부 에셋 의존성 없음. 도감, 몬스터볼, 단순화한 피카츄형 동료, 도검, 성과 격납고는 저장소의 절차적 지오메트리로 직접 구성한 상태. 원작 공식 모델을 확보하거나 사용한 것이 아니며 공식 모델의 정밀 재현도 범위에서 제외. 로고, 원작 영상, OST, 성우 음성 및 외부 음원 다운로드 없음. 14개 효과음은 로컬 수학적 합성, 썸네일은 실제 렌더링 결과 사용. 향후 공식 또는 고정밀 캐릭터 모델로 교체하려면 별도 모델 파일과 사용 허가 확인 필요.

Glass와 Glacier의 투과 재질은 opacity 1을 유지하며 transmission, thickness, IOR와 환경 반사 사용. 내부 구조는 메시와 선으로 구성. 모든 이펙트는 실제 3D 좌표와 깊이 관계 사용. 외부 모델, 이미지 생성 API, 음원, 상시 배경음, CSS 파티클과 공통 bloom 사용 없음.

renderer, 각인 아틀라스와 환경 맵은 씬 수명 동안 공유. 테마 준비 중 기존 장면 유지, 준비 후 모델과 hit target 및 사운드 함께 교체. 빠른 선택은 마지막 요청만 반영. 이전 모델의 geometry, material, texture와 instanced 리소스 정리. 실패 시 기존 모델과 문장 유지. Chromium에서 네트워크 실패 URL을 제공하는 경우 새 모듈 URL로 재시도하며, 다른 오류 형식의 복구 가능성은 브라우저에 따라 제한.

프레임 업데이트는 Three.js 내부 처리이며 프레임별 React 상태 갱신 없음. 클래스별 초기 생성 시 지오메트리와 이펙트 풀 준비. 타건 시 GPU 리소스 추가 생성 없음. 단일 AudioContext에서 최대 16개 재생 채널, 84개 캐시 버퍼와 300ms 이하 잔향 사용. 음소거, 테마 변경과 탭 숨김에서 모든 소스 정리.

애니메이션 테마는 최근 물리 press edge를 최대 64개까지 보관해 실제 입력 순서로 소비. 이는 텍스트가 아닌 장식용 제한 이력이며 한 프레임 사이 극단적인 이벤트가 몰리면 오래된 장식만 생략. 테마 전환과 reset 시 읽기 위치를 현재 입력으로 맞춰 과거 타격 재생 차단. Spider-Verse의 단계 표현은 장식에만 적용하며 공통 KeyState와 textarea는 프레임 또는 입력 이벤트에 즉시 반응.

| 품질 | DPR 상한 | 그림자 | 투과 해상도 | 입자 / 불꽃 / 파동 |
| --- | --- | --- | --- | --- |
| 기본 | 2 | 2048 | 0.5 | 128 / 48 / 12 |
| 저품질 | 1.25 | 1024 | 0.35 | 48 / 20 / 4 |

모바일은 저품질 우선, 지속적인 데스크톱 프레임 저하 시 저품질 전환. 핵심 실루엣과 압축 변형 유지. 정적인 클래식은 안정 후 RAF 정지, 실험 및 애니메이션 테마는 필요한 idle만 유지. 모션 감소 시 부유, 공전과 큰 파동, 대표 연출 및 탄성 초과 복귀 제거. 숨겨진 탭에서는 RAF와 오디오 정지.

Playground 문장과 선택 상태는 페이지 메모리에만 보관. 개인 자유 입력 텍스트의 저장과 전송 없음. localStorage 사용은 Challenge 조건, 결과와 진행 이력에 한정. 분석 도구, 외부 API, 쿠키와 백엔드 없음. 테마 코드와 정적 썸네일만 동일 출처에서 로드.

## 검증과 아트 디렉션

현재 검증 결과, 브라우저와 GPU 조건, 미확인 범위는 [검증 기록](docs/verification.md) 참고. 운영체제의 실제 한글 IME, 실제 휴대폰 소프트웨어 키보드와 직접 청취는 자동 테스트로 대체하지 않는 항목.

```sh
node scripts/capture-scenes.mjs       # 14개 idle/hold, ANIMATION 일반/Enter/Space 캡처
node scripts/generate-thumbnails.mjs  # 실제 씬으로 public/themes와 비교 이미지 생성
node scripts/render-sound-demo.mjs    # 14개 프로필의 청취용 WAV와 타임라인
node scripts/capture-challenge.mjs    # 준비, 경기, 결과와 실제 Ghost 화면
node scripts/measure-challenge.mjs    # 가짜 시계 없는 30초 경기와 모드 전환 리소스 검사
```

위 캡처 스크립트는 개발 서버 실행 필요. 산출물은 Git에서 제외되는 `artifacts/`에 보관, 실제 LNB 썸네일 14개는 `public/themes/`에 포함. 비교 WAV는 합성 소스의 미리보기이며 브라우저의 마스터 압축기와 리미터를 거친 녹음은 아님.

기존 Studio, Dark와 Neon 아트 디렉션은 `src/keyboard/presets.ts`, 신규 테마 환경은 `src/themes/appearances.ts`, 각 모델은 해당 테마 모듈에서 조정. 반응형 배치는 `src/styles.css`, 전체 배열은 `src/keyboard/layout.ts`에서 관리.
