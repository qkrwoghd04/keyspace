# 디지몬 디지털 파트너

귀멸의 칼날 테마를 대체하는 로컬 절차적 3D 장면. 공식 모델, 이미지와 OST 사용 없음. 기존 82키 ANSI 배열과 native 편집 유지.

## 형태와 반응

- 주황색 범퍼, 아이보리 하우징, 녹회색 키캡, 후면 LCD와 조작 버튼, 우측 디지바이스 형태의 파트너 도크.
- 일반 타건: 실제 키의 3D 좌표에서 도크로 이동하는 작은 데이터 큐브, LCD 막대 충전, 아구몬의 시선과 꼬리 반응.
- Enter: 아구몬 → 그레이몬 → 메탈그레이몬 → 워그레이몬 순차 진화. 각 단계는 시간 제한 없이 유지하며 최종 단계의 Enter는 고리 연출만 재생. Reset으로 아구몬 복귀.
- 진화 외형: 그레이몬의 세 뿔과 몸통 무늬, 메탈그레이몬의 반쪽 금속 얼굴과 기계 팔 및 날개, 워그레이몬의 인간형 금색 갑옷과 양손 클로 및 등 방패.
- Space: 아구몬의 베이비 플레임, 그레이몬의 큰 화염, 메탈그레이몬의 쌍발 미사일, 워그레이몬의 머리 위 에너지 구체 충전 및 발사. 입력 문자와 줄바꿈은 원래 의미 그대로 유지.
- Challenge: 데이터 반응, 기술과 진화 억제. 물리 키 눌림과 사운드만 유지. Playground에서 4단계 진화 가능.

## 경계

진화 장식은 `Signature`의 기존 1.15초 실행 및 0.2초 쿨다운 사용. 연출 중 반복 요청은 연장이나 대기열 생성 없이 무시. 일반 입력과 브라우저 텍스트는 제한하지 않는 구조.

| 풀 | 기본 | 저품질 |
| --- | --- | --- |
| 데이터 큐브 | 48개, 720ms | 18개 |
| 화염 입자 | 32개 | 12개 |
| 진화 고리 | 3개 | 3개 |
| 미사일 / 에너지 구체 | 2개 / 1개 | 2개 / 1개 |

모든 단계와 기술의 객체는 테마 초기화 시 한 번 생성, 진화 시 GPU 객체 추가 생성 없음. 진화의 40% 지점에서 형상 교체, 변화 중 추가 Enter는 다음 단계로 예약하지 않는 처리.

모션 감소와 Challenge에서는 idle 이동, 패킷, 화염 및 진화 억제. reset, blur 및 테마 전환 시 이전 반응과 진화 초기화. 소프트웨어 IME 확정에는 임의의 물리 code를 추정하지 않는 처리.

캐릭터는 공식 고정밀 모델이 아닌 작은 장난감 형태의 재해석. 사운드는 로컬 합성 클릭과 3음 신호이며 원작 음악 사용 없음.

## 검증

- `src/themes/digimon/digimon.test.ts`: 테마 교체, 최종 진화와 단계 상한 및 reset, 4단계 기술과 고정 geometry, 진행 중 진화 취소, 2,000회 입력의 고정 GPU 풀, 낮은 품질과 모션 감소, Challenge 입력 분리.
- `tests/e2e/digimon.spec.ts`: 귀칼 UI와 모듈 요청 제거, 실제 Enter/Space로 최종 진화 및 문자 보존, 6개 화면 크기의 최종 진화 및 에너지 구체, reset과 Chromium IME. Challenge 효과 억제는 challenge.spec.ts에서 확인.
- 기존 14개 테마 입력, 6개 화면 크기, IME, 사운드 및 Challenge 회귀 재사용.
- `scripts/capture-digimon.mjs`: 4단계 캐릭터, 기술 및 모바일 캡처와 무음 진화 영상.
- `scripts/measure-digimon.mjs`: 단독 Chrome 실행, 실제 30초 native 타이핑, 모든 단계와 기술 워밍업 후 8회 테마 왕복의 리소스 검사.

최종 실행 결과는 [공통 검증 기록](verification.md) 참고. 실제 OS IME, 실제 휴대폰 GPU, Safari, Firefox의 디지몬 전체 동작 및 사운드 직접 청취는 별도 미검증 범위. 운영 배포 미포함.
